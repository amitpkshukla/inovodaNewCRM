## 3. UI/UX Specification (The Account 360 Page)

When a user clicks a company from the search bar, they land on `/accounts/[id]`. This is the most critical page.

**Layout:** 3-Column Grid + Bottom Input Bar.

### Left Column: Account Health (KPI Cards)
*   Card 1: **Health Status** (Colored badge: Critical = Red, Healthy = Green).
*   Card 2: **Health Score** (e.g., -50).
*   Card 3: **Open Pipeline** (e.g., $0).
*   Card 4: **Oldest Opp** (e.g., 302 Days).
*   Card 5: **Next Meeting** (e.g., Not Planned).

### Center Column: Detailed Data Tables
*   **Section 1: Key Contacts (Decision Makers)**
    *   *Table Columns:* Designation | Name | Contact No. | Mobile No. | Email ID | LinkedIn | Last Meeting | Next Meeting | Appointment Given | Meeting Status | Product | OPP Snapshot.
    *   *Action:* Clicking a row selects that contact as the active target for the Input Box at the bottom.
*   **Section 2: Other Contacts (Influencers)**
    *   *Table Columns:* Same as above, but filtered where `is_key_contact = false`.
*   **Section 3: Product Portfolio**
    *   *List:* Active Products vs. White-Space (e.g., "Core Cluster Management - Active" / "Zero-Trust Identity Bridge - White-Space").

### Right Column: Deterministic Suggested Moves
*   Shows the rules fired by the backend (e.g., "Competitor X mentioned", "Coverage gap: No CMO").
*   **Configurator Button:** Clicking a product here opens the "Safety Brake" modal (checking `product_exclusions` and `vendor_authorization`).

### Bottom Bar: The Input Box
*   **Context Text:** "Log interaction for [Selected Contact Name] or General Account".
*   When the user hits send, it saves the remark, updates the tables, and refreshes the Right Column.

## 4. Backend API Requirements (FastAPI)

### A. Auth Endpoints
*   `POST /auth/login`
*   `GET /auth/me` (Returns user role and assigned accounts).

### B. Data Endpoints
*   `GET /api/companies`: Returns list for search.
*   `GET /api/companies/{id}/hub`: Returns Company details, Key Contacts, Other Contacts, and Products in one JSON.
*   `POST /api/interactions`: Saves the remark, runs the Python Perception Engine, and returns updated Suggested Moves.
*   `POST /api/companies`: Creates a new company (Deduplication check required).

### C. Excel Ingestion
*   `POST /api/import/upload`: Accepts `.xlsx`, reads headers using `pandas`.
*   `POST /api/import/execute`: Maps data to `companies` and `contacts` tables, handling the horizontal date unpivoting.
